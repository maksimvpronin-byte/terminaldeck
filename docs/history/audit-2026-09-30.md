# Проверка TerminalDeck — 30 сентября 2026

Проверена версия 0.23.1. Исправлены пять проблем из первоначального аудита,
после чего выполнены пять последовательных проходов по коду с исправлениями
и целевыми тестами после каждого прохода. В конце выполнены общие проверки.

## Исходные исправления

- Ошибки `statSync` при локальном редактировании обрабатываются и передаются
  в интерфейс; задача таймера больше не оставляет необработанный Promise.
- Одиночное удаление хоста перечитывает сохранённые данные при частичном сбое.
- Закрытие SSH отменяет создание наблюдателя и запуск редактора после загрузки.
- Команда внешнего редактора поддерживает кавычки внутри аргументов, пустые
  аргументы и все вхождения `{file}`; незакрытые кавычки сообщаются как ошибка.
- Отделение панели сохраняет контекст оформления коллекции.
- Удалён неиспользуемый экспорт `LOGON_WARNING`. Экспорты для тестов сохранены.

## Пять дополнительных проходов

| Проход | Область | Подтверждённые проблемы и исправления |
| --- | --- | --- |
| 1 | Очереди SFTP и жизненный цикл панели | Ожидание конфликта завершается при закрытии панели; очередь не запускает следующие передачи после закрытия или смены соединения. Старый результат не обновляет новую панель. Двойное подтверждение запускает передачу один раз. |
| 2 | Сохранение и удаление связанных данных | Папки, учётные записи, inventory и локальные настройки перечитываются после ошибок, которые могли возникнуть после записи части изменений. Применение Git-папки обновляет обе связанные части состояния. Первоначальная ошибка не заменяется ошибкой перечитывания. |
| 3 | Чтение Ansible inventory | Протокол и порт RDP наследуются через предков группы. Недопустимые порты отвергаются. Повреждённые файлы переменных сообщаются как ошибка синхронизации; порядок файлов переменных стабилен, каталоги с суффиксом YAML не читаются как файлы. |
| 4 | Импорт и восстановление резервных копий | Дубли проверяются во всех списках экспорта. Весь журнал проверяется до первой записи. Несовпадение хранилища паролей не выдаётся за успешное восстановление. Журнал сохраняется при ошибке; запуск приложения останавливается с объяснением. Проверено восстановление производных Git-групп с путями в идентификаторах. |
| 5 | Запуск, вкладки и настройки | Повреждённые деревья панелей и повторяющиеся идентификаторы не передаются компонентам. Активные ссылки нормализуются, старые соединения удаляются при чтении. Перенос в отсутствующее рабочее пространство не теряет вкладку. Типы, диапазоны и перечисления сохранённых настроек проверяются. |

## Проверки

После изменений добавлены 39 тестовых сценариев. Целевые проверки каждого
прохода прошли. Общий запуск: **123 тестовых файла, 1130 успешных тестов,
4 пропущенных теста**. Пропуски существовали до изменений.

Успешно выполнены:

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build`
- `npm run format:check`
- `npm run verify:release`
- `npm run verify:performance`
- `git diff --check`

В jsdom остаются сообщения о неподдерживаемом Canvas при импорте xterm.
Они существовали до изменений и не приводят к падению тестов.

## Пределы проверки

Проверки включают чтение исходников, тесты компонентов и модулей, сценарии
ошибок с подменой файловой системы и соединений, локальные Git-репозитории,
сборку и штатную проверку производительности. Реальные SSH/RDP-серверы,
упакованные приложения Windows/Linux и нативные диалоги Electron вручную
не проверялись. Результат не означает доказанного отсутствия всех багов.

Изменения находятся в рабочем дереве; коммит и публикация не выполнялись.
